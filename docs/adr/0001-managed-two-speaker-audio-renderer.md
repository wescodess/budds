# Use a managed native two-speaker Audio Renderer

Budds will use paid Gemini 2.5 Flash Preview TTS as the initial production Audio Renderer because its native joint two-speaker and performance-direction capabilities best satisfy the listening-quality target at an estimated cost below $0.20 for a ten-minute Audio Overview. The model remains behind a versioned adapter, kill switch, and blind listening gate because it is a preview dependency; Aura will not be a silent fallback, and self-hosted Dia remains an evaluation option rather than the production default.
