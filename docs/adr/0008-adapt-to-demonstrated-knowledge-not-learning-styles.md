# Adapt to demonstrated knowledge, not learning styles

Budds will not assess, store, display, or route on a learner's "learning style", because evidence that matching instruction to style improves outcomes is too weak to adopt (`docs/research/learn-anything-evidence.md`). The Void will instead keep a cross-topic Learner Model with three separate layers: Knowledge, updated only by unassisted attempts and the only layer that can change mastery; Support, derived from attempts, assistance, and confidence calibration; and Preferences, set explicitly by the learner. Content fit sets the default format, Knowledge and Support set the amount of help, and Preferences break ties but can never skip retrieval. A learner can see and edit the model. Learning which format helps a specific person remains an experiment judged only on delayed unassisted results.
