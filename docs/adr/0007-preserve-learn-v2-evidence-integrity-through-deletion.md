# Preserve Learn Anything V2 evidence integrity through deletion

Published V2 teaching, feedback, and assessment will require atomic support from a user-accepted source snapshot with a permitted excerpt or stable locator, directional entailment, and no unresolved conflict. Search snippets and model memory are discovery inputs, never evidence. Unknown retention rights store metadata, hashes, and locators only. Source or access deletion purges protected excerpts and private identifiers, retains non-sensitive integrity tombstones, marks historical citations `evidence_unavailable`, and preserves completed attempt history; account deletion still removes the owner's V2 records and performs provider-first cleanup where required.
