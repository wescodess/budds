## Successes

1. **`courseScoped` flag strategy** — Elegant reuse of existing quiz/flashcard/audio infrastructure instead of parallel tables. Established in 1.1, used consistently through all stories.

2. **Task linkage pattern** — Matured across 1.2→1.6. Course creation → outline generation task → section generation task. Reusable for all async pipelines in Epic 3+.

3. **Clean component composition in 1.7** — OutlineEditor, PaceSelector, StartLearningButton composed into CourseCreator with zero rebuild. Props/emits interface held.

4. **Native HTML5 DnD** — Used native drag-and-drop over library dependency (vuedraggable not in project). Fewer deps, sufficient for MVP.

5. **Test coverage trajectory** — Grew steadily from 6 to 506 Convex tests with zero regressions across all stories. Component tests introduced in 1.5 and grew to 33.

6. **Tolerant JSON parser** — Built in 1.4 for LLM response parsing. Trailing-comma cleanup + zod validation. Reusable pattern.

## Challenges

1. **Error handling deferred** — Components in 1.5 and 1.6 shipped without try/catch + toast. Resolved as a batch in 1.7 integration story. Pattern of pushing UX concerns to later stories.

2. **Large-folder transaction limits** — Folders with 200+ docs risk Convex transaction cap when creating courseSourceDocs. Noted in 1.2/1.3, not addressed.

3. **Duplicate `requireAuth` helpers** — 5+ files each define their own inline auth guard. Growing pattern debt.

4. **Accessibility gap** — No aria-labels on OutlineEditor interactive buttons (drag handle, remove). WCAG violation shipped knowingly.

## Key Insights

1. **Public mutations with auth guards** instead of internal mutations — ConvexHttpClient cannot call internal functions. Established pattern for all server→Convex calls.

2. **Error handling must be mandatory from story 1** — Deferring to integration stories creates cleanup debt. Code review should enforce try/catch + toast on all component mutations.

3. **Post-epic E2E testing** — Unit/integration tests verify code correctness but not user flow correctness. Chrome MCP E2E pass needed after each epic.
