## Successes

1. **Pure function architecture.** Both the mastery state machine (`transitionMastery`) and streak evaluator (`evaluateStreak`) are pure functions extracted to `convex/lib/`. This made them trivially testable — 33 tests for logic that has zero database coupling. Pattern should be replicated.

2. **Shared component extraction.** Story 4-1's code review caught the DRY violation between top-level and folder-scoped course views. Extracting `CourseViewBody.vue` as a shared component was the right call — it prevented a class of "fixed in one view, broken in the other" bugs.

3. **Content flagging as first user feedback loop.** Story 4-4 introduced the first user-initiated correction mechanism. The `effectiveAnswer`/`effectiveDefinition` pattern (use corrected value if available, otherwise original) propagates corrections immediately via Convex subscriptions. Clean pattern for future correction surfaces.

4. **Streak system integrated cleanly.** `getOrCreateProfile` helper consolidated profile creation that was duplicated between `courses.create` and section completion. Reduced from 3 creation sites to 1 shared helper.

5. **Zero regressions across all 4 stories.** Despite touching core data flows (mastery computation, streak tracking), no existing tests broke. The prep sprint's test baseline fix (prep-3-5) continues to pay dividends.

## Challenges

1. **Story runners sometimes stop before commit/PR.** Story 4-2's runner completed code review but didn't commit or create a PR. The orchestrator had to manually commit, push, and merge. This happened once before (3-1). Root cause: the runner's context window may be exhausting before the full pipeline completes.

2. **Deferred items continue accumulating.** 11 new deferrals in Epic 4 (vs 20 in Epic 3). The rate is improving but the total backlog (deferred-work.md) is substantial. Most are low-severity but some (UTC-only streak dates, FR16 format override) are functional gaps.

3. **UTC-only streak computation.** The streak system uses UTC dates, not user timezone. For users near the international date line, midnight activities could misattribute days. A `timezone` field exists on `learnProfile` but no UI sets it.

4. **Decisions log growing large.** The orchestrator state file's decisions_log now has 15+ entries spanning multiple epics. Consider archiving per-epic.

## Key Insights

1. **Pure function extraction is the best testability pattern.** `transitionMastery` and `evaluateStreak` are the two most comprehensively tested pieces of logic in the codebase (33 tests combined). Zero mocking needed. Any complex Convex mutation should extract its logic to a pure function in `convex/lib/`.

2. **Prep sprints work.** Three consecutive prep sprints achieved 100% follow-through (7/7 Epic 2→3, 3/3 Epic 3→4). The mandatory gate pattern is validated. Continue for fast-follow epics.

3. **Code review catches ~2 blockers per story consistently.** 7 blockers across 4 stories (1.75 avg). The pattern holds across all 4 epics. Adversarial review is non-negotiable.

4. **Component extraction during review is high-value.** CourseViewBody extraction (4-1) and getOrCreateProfile consolidation (4-3) were both review findings, not planned tasks. Reviews that improve architecture (not just find bugs) are the most valuable.
