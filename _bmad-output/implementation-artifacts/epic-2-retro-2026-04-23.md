## Successes

1. **Component reuse across stories** — CourseCard and CreateCourseCard built in 2-1 reused in 2-2 with just a `folderId` prop addition. Clean interface design.

2. **Void system integration** — Adding courses to the existing sidebar void pattern (FolderShellRail) followed the chat/flashcards/quiz pattern perfectly. Architecture held up.

3. **Cascade deletion depth** — 2-3 covered full cascade: courseSections → courseSourceDocs → course-scoped quizzes (with children) → flashcardRooms (with cards/versions) → audioOverviews (with interjections + storage). Review caught missing `audioOverviewInterjections` cascade.

4. **Faster delivery** — 3 stories completed in one orchestrator run with zero retries. Improved from Epic 1's multi-session execution.

5. **ATDD adoption** — Story 2-3 introduced ATDD-style component tests for the delete dialog.

## Challenges

1. **Epic 1 prep sprint skipped entirely** — All 5 action items remain unaddressed. `requireAuth` duplication now in 6+ files. Aria-labels still missing.

2. **Entity ID resolution inefficiency** — `deleteCourse` uses 3 try/catch `db.get()` calls per entity because `contentBlocks` don't store entity type.

3. **Folder membership not verified** — Folder-scoped course view doesn't verify course belongs to the URL's folder. Cosmetic but architecturally inconsistent.

4. **Pre-existing test failures persist** — `audio-script-prompt.test.ts`, folder-view, folder-documents tests still broken on dev baseline.

5. **Course status not surfaced** — `listByUser` returns generating/failed courses but CourseCard shows them identically to ready courses.

## Key Insights

1. **Props-first component design** — The `folderId` prop pattern made CourseCard work in both top-level and folder-scoped contexts without duplication. Apply to all new components.

2. **Code review catches real bugs** — Both epics had blockers caught in review (double-start guard in 1-6, audioOverviewInterjections cascade in 2-3). Adversarial review is proving its value.

3. **Schema design affects deletion complexity** — Not having `courseId` on course-scoped entities forced indirect `contentBlocks[].entityId` resolution. Store entity type alongside entityId in Epic 3.
