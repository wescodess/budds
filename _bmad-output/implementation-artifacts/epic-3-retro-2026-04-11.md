## What Went Well

- **Third consecutive 100% epic completion** — Process maturity validated across three epics of increasing complexity
- **ATDD workflow scaled to complex integration stories** — Tests pre-written by TEA agent, then turned green by dev agent. Story 3.1: 29 tests, Story 3.3: 12 tests — all transitioned from RED to GREEN
- **All 7 Epic 2 prep items completed (7/7)** — Prep work discipline proven: spikes for Convex file storage and AI Search upsert directly enabled Stories 3.1 and 3.2; security fixes, test fixes, and UX fixes all done
- **Test suite nearly tripled** — From 55 to 153 tests with zero regressions. External service test patterns established (fetch mocking for Cloudflare AI Search)
- **Code review caught critical security gaps** — Server-side file validation (3.1) and userId enforcement in API callers (3.2) both caught and patched in review
- **`searchDocuments()` gateway pattern** — Single function enforces per-user isolation for all future features (chat, quiz, flash cards). Clean architecture.
- **Significant scope increase handled well** — Epic moved from CRUD operations (Epics 1-2) to multi-service integration (Convex storage + PDF parsing + Cloudflare AI Search). Shipped at same 100% quality bar.

---

## Challenges

- **`convex-test` scheduler limitation** — `finishInProgressScheduledFunctions` fails with 'Transaction already committed or rolled back' when actions call `ctx.runMutation`. Integration tests for ingestion pipeline test pieces in isolation rather than the full scheduling path.
- **Story 3.2 was a complexity hotspot** — 11 review findings (most of any story), 6 deferred items. The ingestion pipeline is the most complex piece built so far and has the most loose ends.
- **Security enforcement gaps in initial implementations** — 2/3 stories had security gaps caught in code review: missing server-side file validation (3.1), API callers not passing userId to searchDocuments (3.2). Review process working as intended.
- **Deferred AI Search metadata update on move** — Story 3.3 deferred updating `folderId` in AI Search when documents are moved. This directly affects folder-scoped search in Epic 4 Story 4.1.

---

## Key Insights

1. **Prep work discipline is now a proven pattern** — 7/7 items completed from Epic 2 retro. Three consecutive epics validating: assigned items with clear owners get done, unassigned items drift.
2. **ATDD scales to complex integration stories** — Test-first workflow worked for file storage, PDF parsing, and AI Search integration, not just CRUD.
3. **Code review is the security safety net** — Security enforcement gaps caught and patched in 2/3 stories. Trust the process, don't add ceremony.
4. **V1 pragmatic scoping works when documented** — Deferring Task 4 in Story 3.3 (AI Search metadata update on move) was the right call. Now addressing it as prep for Epic 4 when it's actually needed.

## Technical Debt Carried Forward

See `deferred-work.md` for full details. Summary of active items from Epic 3:

**From Story 3.2:**
- No retry/idempotency mechanism for Cloudflare upsert — transient failures permanently mark documents as "failed"
- Race condition: file deletion between `createDocument` commit and `ingestDocument` execution — handled gracefully
- No timeout wrapping for `pdf-parse` — Convex platform timeout (~300s) is safety net
- `pdf-parse` npm package test-file side effect — unverified in Convex serverless runtime
- Documents table lacks `createdAt`/`updatedAt` fields — observability gap

**From Story 3.1:**
- `updateDocumentStatus` doesn't clear `failureReason` on non-failure transitions — stale data, not user-visible
- `folderDepth` defaults to 1 while `allFolders` loads — pre-existing from Epic 2

**From Story 3.3:**
- Move folder picker renders flat list, not a tree — UX enhancement

**Pre-existing (carried from earlier epics):**
- SQLite single-process auth store — V1 constraint
- Symbol introspection for ConvexClient access — awaiting upstream `nuxt-convex`
- Component tests lack interaction-level coverage
- `onSelect` in FolderTree both emits and navigates
- Dynamic `await import('vue-sonner')` on every toast call
- Various pre-existing chat.vue issues (model validation, score range, response shape, scroll-on-error)
