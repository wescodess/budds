What are the key differences between SN1 and SN2 reactions?
SN1 and SN2 reactions differ in several fundamental ways:

SN2 (bimolecular) proceeds in a single concerted step where the nucleophile attacks the substrate simultaneously as the leaving group departs 1. The rate depends on both substrate and nucleophile concentration.

SN1 (unimolecular) proceeds in two steps: first the leaving group departs to form a carbocation intermediate, then the nucleophile attacks 2. The rate depends only on substrate concentration.

Key distinguishing factors include substrate structure (SN2 favors primary carbons, SN1 favors tertiary) 3, solvent effects, and stereochemical outcomes (SN2 gives inversion, SN1 gives racemization).

What are the key differences between SN1 and SN2 reactions?
SN1 and SN2 reactions differ fundamentally in mechanism, kinetics, and stereochemistry:

SN2 (bimolecular nucleophilic substitution)
Proceeds in a single concerted step where the nucleophile attacks from the back side 1. Rate = k[substrate][nucleophile]. Produces inversion of configuration (Walden inversion).

SN1 (unimolecular nucleophilic substitution)
Two-step process through a planar carbocation intermediate 2. Rate = k[substrate]. Produces racemization because nucleophile can attack from either face.

The choice between pathways depends primarily on substrate structure: methyl and primary substrates favor SN2, while tertiary substrates favor SN1 3.

Design Direction Comparison

D1: Classic Three-Panel

Sidebar + Chat + Source Panel. Most familiar pattern. Sources always visible.

✓ Proven pattern (NotebookLM, ChatGPT)
✓ Sources always accessible
⚠ Three columns tight on smaller screens
⚠ Source panel takes space even when not needed

D2: Inline Citations

Sidebar + wide chat. Sources as expandable chips below messages.

✓ Maximum chat width
✓ Sources in context of message
⚠ Can't compare sources across messages easily

D3: Full-Width Chat

No sidebar. Folder context as pills. Focused conversational experience.

✓ Most immersive chat experience
✓ Best mobile parity
⚠ Folder navigation requires extra step
⚠ No persistent tree view

D4: Study Mode Tabs

Tabs for Chat/Cards/Quiz/Docs within folder context.

✓ Clear mode separation
✓ All features discoverable
⚠ Can't see chat + cards simultaneously
⚠ Tab switching interrupts flow

D5: Dashboard Home

Card-based overview as entry point before diving into study modes.

✓ Great for returning users
✓ Shows knowledge base at a glance
⚠ Extra click to start studying
⚠ Not a complete layout (needs inner view)

D6: Split View

Chat + Study materials side by side. Maximum understand-to-retain flow.

✓ Seamless mode transition
✓ Chat and cards in parallel
⚠ Desktop-only (too cramped on mobile)
⚠ Complex layout to implement

Recommended Combination

D4 (Study Mode Tabs) as the primary structure with D1's source panel for the chat tab, D5's dashboard as the home/entry view, and D3's full-width approach for mobile. This gives explicit study mode discovery (tabs), familiar chat+sources layout, a welcoming home view, and mobile-first responsive behavior.
