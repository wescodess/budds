# Budds

Budds turns a learner's selected source material into grounded study experiences. The Nuxt application combines source-aware chat, quizzes, flashcards, courses, calendar-based review, and durable two-host Audio Overviews backed by Convex and Cloudflare.

## Production status

Budds is in production-hardening. Local validation is comprehensive, but the repository does not claim a production-ready Audio Overview release until the provider, cost, acoustic-quality, and owner listening gates in [`docs/qa/test-plan.md`](./docs/qa/test-plan.md) pass.

## Architecture

- **Web application:** Nuxt 4, Vue 3, Nitro, Tailwind CSS, and shadcn-vue.
- **Backend:** Convex queries, mutations, actions, scheduled jobs, and Better Auth.
- **AI control plane:** Cloudflare AI Gateway, AI Search, Workers AI, and OpenRouter.
- **Audio generation:** A standalone Cloudflare Workflow renders scenes, evaluates quality evidence, assembles private R2 media, and publishes authoritative state through Convex.
- **Deployment:** Cloudflare Pages, Convex Cloud, and a separately deployed Audio Overview Worker.

See [`docs/architecture.md`](./docs/architecture.md) for the system design and [`CONTEXT.md`](./CONTEXT.md) for canonical domain language.

## Requirements

- Node.js 22.19 or 24.11 and newer compatible releases
- pnpm 9.12.3
- A Convex deployment
- Cloudflare and model-provider credentials for the features you run

## Local development

```bash
pnpm install
pnpm dev:stack
```

Copy the documented example files and configure ignored local environment files before starting provider-backed features. Never commit credentials or place private values in Nuxt public runtime configuration.

See [`docs/development-guide.md`](./docs/development-guide.md) for the complete environment contract and individual service commands.

## Validation

```bash
pnpm verify
pnpm build
```

`pnpm verify` runs lint, application and Convex typechecks, all application and Worker test suites, and dependency audits. `pnpm build` validates the production environment contract, builds the Cloudflare Pages artifact without secret-bearing environment defaults, and scans the output for configured secret values.
